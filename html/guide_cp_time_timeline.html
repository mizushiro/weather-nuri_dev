TimeTimeline Component Developer Guide

기상 및 예측 데이터를 시간대별로 선택하고 탐색할 수 있는 데이터 기반 타임라인 선택기 & 플레이어 컨트롤러 컴포넌트입니다.
자동 재생 기능, Sticky 날짜 헤더, 선택 요소 중앙 자동 스크롤, PC 드래그 스크롤 및 동적 데이터 업데이트 API를 지원합니다.

📅 요일 및 월/일 자동 파싱 ▶️ 자동 재생 & 속도 조절 🎯 선택시 중앙 스크롤 정렬 🖱️ PC 마우스 드래그 스크롤
디바이스 뷰포트 전환 데스크톱 및 모바일 렌더링 상태를 실시간으로 비교 확인합니다.

📅 1. 타임라인 컴포넌트 데모 (Live Interactive Demo) (상단 뷰포트 전환 바로 모바일 프리뷰 지원)

⚡ unit: 'day' 또는 type: 'day' (또는 data-unit="day") 설정 시, 시간이 아닌 날짜 단위로 표시되며 최대 3일치만 균등 분할(1/3)되어 렌더링됩니다. 모바일 및 PC 모두 클릭(터치) 이벤트로 즉시 선택할 수 있습니다.

⚙️ 2. 설치 및 기본 마크업 (Setup & HTML Markup)

CSS 스타일시트와 ES 모듈 JS 파일(uiuxu.common.js)을 가져온 후 HTML 컨테이너 요소를 작성합니다.

1) CSS & JS Import

<!-- CSS --> <link rel="stylesheet" href="../resources/css/ui.base.css"> <!-- JS Module --> <script type="module"> import { UX } from '../resources/js/uiuxu.common.js'; UX.init(); </script>

2) HTML 마크업 컨테이너 & type 속성

<!-- 1. 기본 일반 타임라인 (Default Mode) --> <div data-time-timeline="timeTimelineDemo"></div> <!-- 2. Range 타입 타임라인 (Range Mode - 날짜별 첫시간 스킵) --> <div data-time-timeline="timeTimelineRangeDemo" data-type="range"></div>

📊 3. 데이터 구조 (Data Schema)

data 옵션에는 날짜(day) 및 해당 날짜의 시간 문자열 배열(times)을 포함하는 객체 배열을 전달합니다.

const timelineData = [ { day: '20260701', // 'YYYYMMDD' 또는 'YYYY-MM-DD' 포맷 지원 (월.일 및 요일 자동 파싱) times: ['00', '02', '06', '12', '18'] // 해당 일자의 시각 목록 }, { day: '20260702', times: ['00', '03', '06', '09', '12', '15', '18', '21'] } ];

🛠️ 4. 생성자 옵션 (Constructor Options)

new UX.TimeTimeline(options) 생성자에 사용 가능한 옵션 항목입니다.

옵션명 타입 필수여부 기본값 설명
id string 선택 'timeTimeline_random' 컴포넌트 식별자 및 data-time-timeline 속성 매칭용 아이디
container string | HTMLElement 선택 '[data-time-timeline="{id}"]' 컴포넌트가 바인딩될 컨테이너 요소를 직접 지정할 때 사용
data Array<Object> 필수 [] 타임라인 날짜 및 시간 데이터 배열 ([{ day, times }])
selectedDayIndex number 선택 0 초기 선택될 날짜 데이터의 배열 인덱스
selectedTimeIndex number 선택 0 초기 선택될 시각 데이터의 배열 인덱스
interval number 선택 1000 자동 재생 시 다음 시각(또는 날짜)으로 이동하는 시간 간격 (밀리초, ms)
unit string 선택 'time' 타임라인의 표시 단위. 'time'(기본 시각 단위) 또는 'day'(날짜 단위). 'day' 지정 시 시간이 아닌 날짜 단위로 표시되며, 데이터 중 최대 3일치만 균등 분할(1/3)되어 렌더링되고 클릭 이벤트로 날짜를 선택할 수 있습니다.
onChange function 선택 function(info) {} 사용자 클릭 또는 플레이어로 인해 시각/날짜 선택이 변경되었을 때 실행되는 콜백 함수
type string 선택 null 타임라인 타입 지정 ('range' 또는 'day'). 'range' 설정 시 data-type="range" 속성이 추가되며 자동 플레이 시 각 날짜의 첫시간을 건너뜁니다. 'day' 설정 시 unit: 'day'와 동일하게 날짜 단위 타임라인으로 동작합니다.
text string | string[] 선택 '' 상단 컨트롤 바 우측에 표시할 안내/예보 텍스트 (예: '초단기예보:9월 18일 13시 20분,<br>단기예보: 9월 18일 11시' 또는 줄바꿈 '\n', 문자열 배열 지원). setText()로 동적 갱신 가능

📡 5. onChange 이벤트 전달 객체 (Event Callback Info)

onChange: (info) => { ... } 콜백 실행 시 전달받는 info 객체 명세입니다.

프로퍼티 타입 예시 값 설명
info.day string "20260702" 선택된 날짜의 원본 문자열
info.dayLabel string "07. 02 목" 자동 변환된 날짜 및 요일 표시 라벨
info.time string "09" 선택된 시간 원본 문자열
info.timeLabel string "09시" 시간 표시 라벨
info.dayIndex number 1 선택된 날짜의 배열 인덱스
info.timeIndex number 3 해당 날짜 내 선택된 시간의 인덱스
info.flatIndex number 11 전체 타임라인을 1차원 평탄화했을 때의 절대 선택 인덱스

🔌 6. 주요 메소드 API (Public Methods)

메소드명 파라미터 설명
selectTime(dayIdx, timeIdx, triggerCallback) dayIdx number,
timeIdx number,
triggerCallback boolean = true 		지정한 날짜 인덱스 및 시간 인덱스로 선택을 변경하고 UI와 스크롤을 중앙으로 정렬합니다.
selectByFlatIndex(flatIdx, triggerCallback) flatIdx number,
triggerCallback boolean = true 		전체 1차원 시각 목록의 절대 인덱스 기준으로 시각을 선택합니다.
play() - 자동 재생을 시작합니다. (설정된 interval마다 다음 시각으로 이동)
pause() - 자동 재생을 일시정지합니다.
togglePlay() - 자동 재생 상태를 반전(재생 ↔ 일시정지)시킵니다.
setSpeed(ms) / setInterval(ms) ms number 자동 재생 속도(간격)를 동적으로 변경합니다. (예: 500 = 0.5초)
prevDay() - 이전 날짜의 첫 번째 시각으로 이동합니다.
nextDay() - 다음 날짜의 첫 번째 시각으로 이동합니다.
setData(newData) newData Array<Object> 새로운 타임라인 데이터로 갱신하고 초기화합니다.
setText(text) text string | string[] 상단 안내/예보 텍스트를 동적으로 변경합니다.
getText() - 현재 설정된 안내 텍스트를 반환합니다.
destroy() - 재생 타이머를 정지하고 바인딩된 DOM 콘텐츠를 삭제합니다.

💻 7. 개발자 예제 코드 (Full Example Code)

import { UX } from '../resources/js/uiuxu.common.js'; // 1. 공통 UX 초기화 UX.init(); // 2. 데이터 준비 const sampleData = [ { day: '20260701', times: ['00', '06', '12', '18'] }, { day: '20260702', times: ['00', '03', '06', '09', '12', '15', '18', '21'] } ]; // 3. 컴포넌트 인스턴스 생성 및 바인딩 UI.exe.myTimeline = new UX.TimeTimeline({ id: 'timeTimelineDemo', data: sampleData, selectedDayIndex: 0, selectedTimeIndex: 2, interval: 1000, text: '초단기예보:9월 18일 13시 20분,<br>단기예보: 9월 18일 11시', onChange: (info) => { console.log(`선택 날짜: ${info.dayLabel}, 선택 시각: ${info.timeLabel}`); // 사용자 지도 데이터 갱신 또는 차트 조회가 실행되는 영역 } }); // 4. 메소드 호출 예시 // UI.exe.myTimeline.play(); // 자동 재생 시작 // UI.exe.myTimeline.setSpeed(500); // 0.5초 간격으로 변경 // UI.exe.myTimeline.selectTime(1, 0); // 2번째 날짜의 첫시각 선택 // 5. 날짜 단위(Day Unit) 타임라인 생성 예시 (최대 3일치 균등 분할 & 클릭 선택) UI.exe.myDayTimeline = new UX.TimeTimeline({ id: 'timeTimelineDayDemo', unit: 'day', // 날짜 단위 지정 (또는 type: 'day') data: [{ day: '20260922' }, { day: '20260923' }, { day: '20260924' }], // 최대 3일 selectedDayIndex: 0, text: '초단기예보:9월 18일 13시 20분', onChange: (info) => { console.log(`선택 날짜: ${info.day} (${info.dayLabel})`); } });
