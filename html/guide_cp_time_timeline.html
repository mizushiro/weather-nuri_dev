⚙️ 2. 설치 및 기본 마크업 (Setup & HTML Markup)

📊 3. 데이터 구조 (Data Schema)

data 옵션에는 날짜(day) 및 해당 날짜의 시간 문자열 배열(times)을 포함하는 객체 배열을 전달합니다.

const timelineData = [ { day: '20260701', // 'YYYYMMDD' 또는 'YYYY-MM-DD' 포맷 지원 (월.일 및 요일 자동 파싱) times: ['00', '02', '06', '12', '18'] // 해당 일자의 시각 목록 }, { day: '20260702', times: ['00', '03', '06', '09', '12', '15', '18', '21'] } ];

🛠️ 4. 생성자 옵션 (Constructor Options)

new UX.TimeTimeline(options) 생성자에 사용 가능한 옵션 항목입니다.

옵션명 타입 필수여부 기본값 설명
id string 선택 'timeTimeline_random' 컴포넌트 식별자 및 data-time-timeline 속성 매칭용 아이디
container string | HTMLElement 선택 '[data-time-timeline="{id}"]' 컴포넌트가 바인딩될 컨테이너 요소를 직접 지정할 때 사용
data Array<Object> 필수 [] 타임라인 날짜 및 시간 데이터 배열 ([{ day, times }])
selectedDayIndex number 선택 0 초기 선택될 날짜 데이터의 배열 인덱스
selectedTimeIndex number 선택 0 초기 선택될 시각 데이터의 배열 인덱스
interval number 선택 1000 자동 재생 시 다음 시각으로 이동하는 시간 간격 (밀리초, ms)
onChange function 선택 function(info) {} 사용자 클릭 또는 플레이어로 인해 시각 선택이 변경되었을 때 실행되는 콜백 함수

📡 5. onChange 이벤트 전달 객체 (Event Callback Info)

onChange: (info) => { ... } 콜백 실행 시 전달받는 info 객체 명세입니다.

프로퍼티 타입 예시 값 설명
info.day string "20260702" 선택된 날짜의 원본 문자열
info.dayLabel string "07. 02 목" 자동 변환된 날짜 및 요일 표시 라벨
info.time string "09" 선택된 시간 원본 문자열
info.timeLabel string "09시" 시간 표시 라벨
info.dayIndex number 1 선택된 날짜의 배열 인덱스
info.timeIndex number 3 해당 날짜 내 선택된 시간의 인덱스
info.flatIndex number 11 전체 타임라인을 1차원 평탄화했을 때의 절대 선택 인덱스

🔌 6. 주요 메소드 API (Public Methods)

메소드명 파라미터 설명
selectTime(dayIdx, timeIdx, triggerCallback) dayIdx number,
timeIdx number,
triggerCallback boolean = true 		지정한 날짜 인덱스 및 시간 인덱스로 선택을 변경하고 UI와 스크롤을 중앙으로 정렬합니다.
selectByFlatIndex(flatIdx, triggerCallback) flatIdx number,
triggerCallback boolean = true 		전체 1차원 시각 목록의 절대 인덱스 기준으로 시각을 선택합니다.
play() - 자동 재생을 시작합니다. (설정된 interval마다 다음 시각으로 이동)
pause() - 자동 재생을 일시정지합니다.
togglePlay() - 자동 재생 상태를 반전(재생 ↔ 일시정지)시킵니다.
setSpeed(ms) / setInterval(ms) ms number 자동 재생 속도(간격)를 동적으로 변경합니다. (예: 500 = 0.5초)
prevDay() - 이전 날짜의 첫 번째 시각으로 이동합니다.
nextDay() - 다음 날짜의 첫 번째 시각으로 이동합니다.
setData(newData) newData Array<Object> 새로운 타임라인 데이터로 갱신하고 초기화합니다.
destroy() - 재생 타이머를 정지하고 바인딩된 DOM 콘텐츠를 삭제합니다.

💻 7. 개발자 예제 코드 (Full Example Code)

import { UX } from '../resources/js/uiuxu.common.js'; // 1. 공통 UX 초기화 UX.init(); // 2. 데이터 준비 const sampleData = [ { day: '20260701', times: ['00', '06', '12', '18'] }, { day: '20260702', times: ['00', '03', '06', '09', '12', '15', '18', '21'] } ]; // 3. 컴포넌트 인스턴스 생성 및 바인딩 UI.exe.myTimeline = new UX.TimeTimeline({ id: 'timeTimelineDemo', data: sampleData, selectedDayIndex: 0, selectedTimeIndex: 2, interval: 1000, onChange: (info) => { console.log(`선택 날짜: ${info.dayLabel}, 선택 시각: ${info.timeLabel}`); // 사용자 지도 데이터 갱신 또는 차트 조회가 실행되는 영역 } }); // 4. 메소드 호출 예시 // UI.exe.myTimeline.play(); // 자동 재생 시작 // UI.exe.myTimeline.setSpeed(500); // 0.5초 간격으로 변경 // UI.exe.myTimeline.selectTime(1, 0); // 2번째 날짜의 첫시각 선택
